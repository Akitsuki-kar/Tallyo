# 水电动账 · Tallyo 💧⚡

> 你的水电费，从此有据可查。
> 不再和房东在电表前「深情对视」，也不用在微信里翻三个月前的聊天记录假装自己记得用了多少度电。

> 英文名 **Tallyo** —— *tally*（点数 / 记账）+ 收尾 *o*，俏皮好记。专治「水电读数记不住、账单算不清」。

**水电动账** 是一款离线优先（Offline-First）的 PWA 记账应用，专门解决一个朴实无华的痛点：**租房 / 管房时，水电表读数记不住、账单算不清、多套房一团麻。**

它长得像一本手写的便签本——陶土色封面、纸纹底、圆体字、手写感的大数字。但内核是一套正经的本地数据库 + 加密同步引擎。

## ✨ 核心功能

- **📝 读数记录**：表单录入 + 一键快速记录弹窗，自动按「同房源同类型」链接成读数链，算出本期用量。月内录 N 条也不怕，账单按「月末 − 月初基准」净量计算，绝不少算一分钱。
- **🏠 多房源管理**：一套「我的家」不够？随时增删房源，所有数据按房源维度隔离。管房如管家，几套都不慌。
- **💰 灵活单价**：固定价？阶梯价？都能配。阶梯电价那个让人头大的分档计算，交给它。
- **📊 可视化统计**：ECharts 封装的趋势折线、月度对比柱状、费用构成饼图、指标卡——钱花在电上还是水上，一眼看清。
- **🎯 预算管理**：金额 / 用量双口径预算，80% / 100% 双档预警。月底超支前，先收到一封温柔（但直白）的警告。
- **🧾 账单生成 & 导出**：4 套模板（小票 / 极简 / 卡片 / 报表），一键导出 PDF，直接拍给房东 / 室友 / 自己看。
- **☁️ WebDAV 同步**：坚果云等 WebDAV 全量快照同步，LWW（最后写入获胜）冲突裁决，三层防死循环设计，多设备和平共处。
- **🔒 本地加密**：应用密码用设备本地随机密钥 AES-256-GCM 加密，密钥不落库、不进同步快照、不进日志。
- **📴 离线优先**：PWA 安装到桌面，断网照用，联网自动合并。

### 🛠 近期打磨过的小细节（体验与安全）

- **持久化存储申请**：启动时请求浏览器持久化存储，降低本地账本被静默清理的风险。
- **存储配额兜底**：写入空间不足时不再静默失败，而是提示你「该导份备份了」。
- **同步重试退避**：网络抖一下不会整轮同步崩掉，自动指数退避重试，遇到限流（429）会读 `Retry-After` 礼貌等待。
- **同步冲突透明化**：同步完告诉你「本次合并了 N 处冲突」，多机合并不再是个黑盒。
- **离线横幅 + 待同步计数**：顶部常驻提示「离线 · N 项改动联网后同步」，心里有数。
- **删除撤销**：手滑删了读数 / 房源？5 秒内有「撤销」按钮救你，账本数据删错很痛，我们懂。
- **每周自动备份**：已配同步可开启每周自动把快照备份到远端，持久化之外的第二道防线。
- **设备密钥备份**：用你自己的口令把本机密钥加密备份，换设备 / 清数据后能恢复解密能力，且密钥永不裸奔上云。

## 🧱 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Vue 3 + TypeScript + Vite |
| 状态 | Pinia |
| UI | Vant 4（深度定制为手作美学） |
| 图表 | ECharts 5（按需引入） |
| 存储 | IndexedDB（`idb` 封装）+ 复合索引 |
| 同步 | WebDAV + 自研 LWW 合并引擎 |
| 加密 | Web Crypto（AES-256-GCM / PBKDF2） |
| 报表 | html2canvas + jsPDF |
| 形态 | PWA（vite-plugin-pwa，可安装、可离线） |

工程化：严格 `tsconfig`（`strict: true`，零 `any`）、纯函数测试套件、同源反向代理同步拓扑。

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 本地开发（默认 5173，已配置 /dav 代理到坚果云，方便调试同步）
npm run dev

# 类型检查 + 生产构建（产出 dist/）
npm run build

# 预览构建产物
npm run preview

# 纯函数测试（读数链 / 计费 / 合并 / 配额守卫 / 密钥备份……）
npm run test:pure

# 重新生成 PWA 图标（改了品牌色后用）
npm run gen:icons
```

> 要求 Node 18+（开发环境实测 Node 22 通过）。

## ☁️ 关于同步（重要）

同步走 **WebDAV**。生产部署时，**必须**把 WebDAV 放在与前端**同源**的反向代理后面（如 `你的域名/dav/` → 坚果云），App 里填相对路径 `/dav/...`。

为什么？因为内容安全策略（CSP）只允许 `connect-src 'self'`，跨域直连会被浏览器无情拦截——这不是 bug，是设计。详细的 Nginx 反代示例、CORS 处理、限流建议都写在 [`docs/webdav-setup.md`](docs/webdav-setup.md) 里。

## 🎨 设计理念

这不是又一个「青紫渐变 + 玻璃拟态 + 霓虹高光」的 AI 味 App。

我们选了**有机手作感（organic handcrafted）**：

- 米色纸纹底，像摊开的记账本；
- 陶土色（terracotta）主调，暖而不躁；
- 圆体字形 + 手写感大数字（Caveat 字体本地自托管，离线可用）；
- 全套 OKLCH 色板（tinted neutrals，没有一个纯黑纯白）；
- 深浅主题按「表面提亮」处理，而非粗暴反相。

所有颜色走 `--sdb-*` / `--van-*` CSS 变量，尊重 `prefers-reduced-motion`，也照顾到色弱友好。

## 🔐 安全与隐私

- 数据默认**只存在你本地**（IndexedDB），不经过任何第三方服务器。
- 同步密码用设备本地密钥加密，**密钥不跨设备、不进快照、不进日志**。
- 设备密钥可**主动**用口令加密备份（导出文件 / 上传同步盘），恢复需口令，绝不裸奔。
- 全局错误兜底到位，崩了也会弹提示而不是白屏。
- 想彻底掌控？数据可一键导出 / 导入，格式透明（JSON 快照）。

## 🖥 原生壳（Tauri 2）

想要桌面 / 移动 App 而不牺牲「最小存储、最小内存、最精简」？项目已接入 **Tauri 2**：复用系统原生 WebView，不打包 Chromium，桌面安装包约 5MB、常驻内存约 80MB（Electron 方案是它的 ~20 倍）。

- Vue 业务代码零改动，Web/PWA 与原生壳共用同一套 `src/` 与 `dist/`。
- 原生壳里**可直连 WebDAV**（无浏览器 CORS，无需 Nginx 反代），同步设置填完整 HTTPS 地址即可。
- 详见 [`docs/native-shell.md`](docs/native-shell.md)。快速起手：

```bash
# 1. 安装 Rust 工具链（rustup.rs）与系统依赖（见文档）
# 2. 生成各平台图标（一次性）
npx tauri icon src-tauri/icons/icon.png
# 3. 开发 / 打包
npm run tauri:dev      # 带热更新的原生壳
npm run tauri:build    # 生成对应平台安装包
```
