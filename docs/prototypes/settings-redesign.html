变化：房源是最高频操作，放在第一个分区卡，桌面下跨两列。 行高从「列表卡片」压到 52px，读数条数与「上次记录」合并成一行副标题，删掉原来的卡片套卡片。 当前房源用主色圆章 + 「当前」chip 表达，不再靠边框。最后一个房源仍不可删（保持既有红线）。

外观

变化：主题从「点开 action-sheet 再选」改成卡内三段控件，少一次点击； 三档本来就互斥且数量固定，适合直接铺开。选中态用「浮起纸片 + 柔影」，延续便签感而非 iOS 绿。

行为

变化：给每行加图标 + 副标题（原来只有标题 + 值，含义要靠猜）。 开关行整行可点、但开关本体是独立命中区；「默认视图」保留 action-sheet（5 项、需上下文）。

账单

变化：模板是「看得见的偏好」，用四个带缩略示意（齿边/纯色/描边/表格）的磁贴一眼挑， 替代原来要逐个点开试的纯文字选择。缩略图只是 CSS 画的占位，实现时可直接复用模板组件渲染真实缩略。

变化：同步 / 单价补上副标题（连的是哪个服务、当前单价多少），不用点进去才知道状态。 设备密钥备份默认折叠——它是低频且带风险提示的操作，原来平铺占半屏； 折叠后仍在同一张卡里，展开即见说明与两个按钮，红线文案一条不减。

关于

变化：作者 / 鸣谢 / 引导 / 安装这四项都是「弹一下就完事」的低频动作， 从四行列表压成一行胶囊 chips，省掉约 150px 纵向空间，也让"关于"区不再像设置项。 鸣谢点开后走系统浏览器（本次确认的方案）。
