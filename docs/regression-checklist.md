# 水电动账（SDB）人工回归清单

> 配套 `docs/launch-audit.md`。用于发布前的人工验收，覆盖已实现的**数据安全**与**体验增强**项（高优①②③、体验⑩⑪⑫⑬、密钥备份⑭）。
> 自动化测试仅覆盖纯函数（`npm run test:pure`，52 项）；以下为端到端 / 交互行为，需人工在真机或浏览器走查。

## 0. 发布前必做（构建与基线）
- [ ] `npm run build` 产出 `dist/`，0 错误（沙箱内因安全删除策略需用临时 outDir 验证，本机正常）。
- [ ] `npm run test:pure` → 52 passed, 0 failed。
- [ ] 浏览器 DevTools Console 无未捕获异常（已加 `app.config.errorHandler` 兜底）。
- [ ] PWA 可安装、离线可打开（SW 已生成 36 项 precache）。

## 1. 高优① 持久化存储授权
- [ ] 首次启动弹/提示「已申请永久保存本地账本」（或浏览器原生持久化授权弹窗）。
- [ ] 清站点数据后重新打开，账本仍在（持久化生效）；未授权时顶部出现可关闭提示且不阻塞使用。

## 2. 高优② 配额/写入异常兜底
- [ ] 模拟配额不足（`navigator.storage` 写满或 DevTools 强制 QuotaExceeded）→ 写入操作不静默失败，出现「存储空间不足，请导出备份」类提示。
- [ ] 配额提示出现后，导出数据仍可正常触发（引导用户自救）。

## 3. 高优③ WebDAV 失败重试退避
- [ ] 断网/弱网下一次「同步」：偶发抖动能自动重试（最多 3 次指数退避），最终成功不报错。
- [ ] 坚果云返回 429 时，提示「同步受限，稍后重试」而非整轮失败。
- [ ] 持续不可达时，错误可定位（含参考 `docs/webdav-setup.md`）。

## 4. 体验⑩ 同步冲突透明化
- [ ] 双机/双标签页对同一房源读数各改一次 → 同步完成提示含「合并 N 处冲突」。
- [ ] 同步页显示「上次同步时间」且随时间更新。

## 5. 体验⑪ 离线横幅 + 待推计数
- [ ] DevTools 切到 Offline → 顶部出现「离线·改动将在联网后同步」横幅。
- [ ] 离线状态下录入/修改读数 → 横幅显示「N 项改动待同步」且计数随操作增长。
- [ ] 恢复联网并手动/自动同步 → 横幅消失，计数归零。

## 6. 体验⑫ 删除撤销
- [ ] 删除一条读数 → 底部出现 5 秒「撤销」条；点撤销后读数恢复且账单/读数链重建正确。
- [ ] 删除一个房源 → 同上可撤销；超时后软删已传播（可在同步中看到墓碑）。
- [ ] 5 秒后撤销条自动消失，删除生效。

## 7. 体验⑬ 每周自动备份
- [ ] 设置页开启「每周自动备份」且已配置同步 → 启动后（超出 7 天阈值时）自动写远端 `shuidian-dongzhang/backups/data-YYYYMMDD.json`。
- [ ] WebDAV 中确认备份文件生成；失败仅告警不影响主流程。
- [ ] 7 天内重复启动不重复备份（`lastAutoBackupAt` 生效）。

## 8. 体验⑭ 设备密钥备份与恢复（安全敏感）
**导出**
- [ ] 设置页「设备密钥备份」→ 填口令（≥8 位）两次一致 → 「导出到文件」下载 `水电动账-密钥备份.json`。
- [ ] 口令不足 8 位 / 两次不一致 → 拦截并提示。
- [ ] 已配置同步时「上传到同步盘」→ 远端生成 `shuidian-dongzhang/key-backup.json`。
- [ ] 「上次备份」时间更新。

**恢复（关键：模拟换机/清数据）**
- [ ] 清除站点数据（或换无密钥的设备）→ 原 WebDAV 密码解密本应失败。
- [ ] 「从文件恢复」导入上面的 json + 正确口令 → 提示「密钥已恢复」。
- [ ] 恢复后重新同步/解密密码成功，原同步配置可正常工作。
- [ ] 错误口令 → 提示「恢复失败：口令错误或备份已损坏」，本机密钥不被破坏。
- [ ] 备份文件本身为口令加密 JSON（`v/salt/iv/ct`），明文密钥不进快照/日志（已代码确认）。

## 9. 边界与回归
- [ ] 月内多次读同一类型读数 → 账单金额按「月末−月初基准」净额（非单条差），见 `npm run test:pure` 的 `monthlyUsage` 用例。
- [ ] 双机同步不出现乒乓推送（死循环三层防护：recompute 幂等 / applySnapshot 条件重算 / useAutoSync 事件抑制）。
- [ ] 主题/设置同步开关行为符合预期（`syncTheme`/`syncSettings`）。
